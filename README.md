# Ashpeak - Play Build (Windows)

## How to install and play (Windows)

**System needs:** Windows 10 or 11 (64-bit) and a graphics card (GPU) that supports Vulkan.

1. Download `Ashpeak_v0.2-batch2_win64.zip` (and optionally `INSTALL.txt`) from [Releases](https://github.com/robwalsh147/Ashpeak-play/releases/latest).
2. Right-click the zip > **Extract All** > **Extract**. Do not run the game from inside the zip.
3. Open the extracted folder `Ashpeak_v0.2-batch2`.
4. Double-click **Ashpeak.exe**. The game data is built into the exe, so no other files are needed.
5. If Windows SmartScreen says "Windows protected your PC", click **More info** > **Run anyway**.

**If the game won't start:** update your graphics drivers (NVIDIA, AMD or Intel) and try again.

**To uninstall:** delete the `Ashpeak_v0.2-batch2` folder (and the zip). Nothing else is installed.
