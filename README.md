# Ashpeak — Play Build (Windows)

1. Go to **Releases** (right side of this page) and download `Ashpeak_v0.2-batch2_win64.zip`.
2. Right-click the zip > **Extract All**.
3. Open the extracted folder and run **Ashpeak.exe**.
4. If Windows SmartScreen shows a warning, click **More info** > **Run anyway**.
